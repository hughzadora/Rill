---

name: rill-deliver
description: Deliver software tasks under Rill using native Codex roles and real product-specific quality and behavior checks.
---

Use for a real feature, bug fix or refactor in a repository with Rill installed.

1. Identify the target repo and issue from current GitHub state; no presumed
   task from previous chat and no fabricated owner acceptance.
2. Determine requirements, meaningful failure modes and user-facing flows.
   Use a clickable Chrome prototype when interaction choices actually matter.
3. Delegate bounded investigation/implementation to the shipped native roles
   when appropriate. Every worker owns specific paths and must not self-review.
4. Keep existing product tests running during edits. Add focused tests and
   negative cases; run the generated full applicable native quality workflow.
5. Commission a fresh independent Reviewer at the exact diff/HEAD. Require
   reproducible findings and actual checks; fix, retest and re-review as needed.
6. Leave verifiable GitHub PR/Issue receipts. Owner only decides consequential
   product choices and approves protected operations, not routine fixes.
