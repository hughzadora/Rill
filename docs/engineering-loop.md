# Rill — native engineering quality loop

Updated: 2026-10-22. **Authority:** [kernel](policy.md) > [rebuild plan](../rill-rebuild-plan.md) > this operational reference. [Owner's Quality Gate research](tool-for-quality-gate.md) is kept byte-for-byte as an input, not an alternative policy or configuration.

## Locked stack and ownership

- **Rill first-party executable code:** TypeScript **7.0.2 only** on Node.js **24 LTS**, pnpm **12.14.0**. Shell is an existing command-invocation surface (the two Husky hook entry points); Python is not Rill implementation code. The upstream vendor executables may be implemented in any language.
- **One format writer:** Biome **2.6.2** for TypeScript, JS, JSON, CSS **and Markdown**. Its native Markdown formatter supports GFM and `proseWrap: preserve`; embedded snippets are preserved with `formatEmbeds: false`. Prettier is removed. [Biome 2.6.2](https://biomejs.dev/internals/changelog/version/2-6-2/) and [Markdown configuration](https://biomejs.dev/reference/configuration/).
- **Shared baseline:** `.editorconfig` (UTF-8, LF, two-space ordinary content, final newline), with Justfile's upstream-standard four-space recipe indent exception.
- **Markdown semantic/style lint:** upstream **markdownlint 0.42.0** through its supported API, selected by `tools/check-markdown.ts`. No self-authored Markdown rules, additional format writer, or auto-fixer. **MD032 disabled** because the installed Biome formatter removes blank lines before some lists; MD013 remains disabled (no document-length proxy), MD024 is siblings-only. All other markdownlint rules stay enabled.
- **Owner source:** `docs/tool-for-quality-gate.md` is excluded from formatting and supplementary Markdown lint. Do not rewrite its original typography or claim to have validated its snippets as executable code.

## Single command surface

| Operation                           | Native entry                     | Side effects / evidence                                                                                                                                                                                                                 |
| ----------------------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reproducible project installation   | `pnpm install --frozen-lockfile` | Mutates `node_modules` as normal; must not modify lockfile.                                                                                                                                                                             |
| Confirm local binaries and versions | `just doctor`                    | Fails if installed tool is missing.                                                                                                                                                                                                     |
| Development checks                  | `just check`                     | Formatting, Markdown, TypeScript, tests, Knip, LOC, Lizard and offline Lychee.                                                                                                                                                          |
| Only the explicit formatter         | `just fmt`                       | **Writes** via Biome; verify `just check` and a second zero-diff run.                                                                                                                                                                   |
| Native pre-commit                   | `just precommit`                 | lint-staged read-only checks on **index-selected files**, Gitleaks staged scan; no commit action.                                                                                                                                       |
| Native pre-push                     | `just gate`                      | Development gate with **V8 coverage** replacing normal Vitest run, plus Gitleaks history, Trivy and pnpm audit.                                                                                                                         |
| Refresh security DB                 | `just security-db-update`        | **Requires network**. Full pre-push uses Trivy’s native database refresh when needed; network or refresh failure blocks the gate. `just security-offline` is diagnostic only and must never be reported as a current security sign-off. |
| Remote link audit                   | `just links-online`              | **Network dependent**, can fail due remote rate limit / bot verification / DNS; result is not equivalent to local link validation.                                                                                                      |
| Machine-readable tests              | `just report`                    | Vitest JSON under ignored `coverage/`; reports are evidence not a model quality score.                                                                                                                                                  |

The workflows use supported upstream native CLI commands. `justfile` expresses their order, not a new orchestration/runtime framework. Check modes must not stage, rewrite, suppress errors or proceed after a nonzero result. Fix is a separately authorized mechanical operation before staging.

## Verification and outstanding limits

**Verified on macOS:** frozen-lock installation; `just check`; `just gate`; Vitest 2/2 package-schema positive/negative tests; repeat formatter convergence; real Husky pre-commit preserving partial staging, rejecting malformed staged code without changing HEAD/index; local bare remote `pre-push --dry-run` rejects broken code/accepts clean; TS type error; Biome invalid formatting; Markdownlint MD012; Tokei 501 LOC; Lizard CCN >15; Knip unused file; Lychee broken relative link; Gitleaks synthetic staged secret redacted; Trivy Dockerfile HIGH misconfig; Vitest uncovered production file fails coverage thresholds. Temporary test files and repos were removed. The current tool matrix itself is preserved.

**Current behavior task:** [issue #3](https://github.com/hughzadora/Rill/issues/3) exercises the real LOC helper, including malformed reports and the 500/501 boundary; its candidate-matched test, coverage and separate-agent review evidence are attached to the delivery PR. Coverage includes this helper and future `src/**/*.ts`; it does not currently include the separate Markdown CLI adapter.

**Not yet verified:** execution through the actual macOS Codex App project, automatic instruction/skill discovery, GUI actions/PATH, native selector rendering, account usage/reset visibility and cross-session App recovery. External HTTP availability and future product behavior are separate scopes. Trivy evidence is current only for the recorded scan. Paid GitHub private-repository protections are out of scope. Follow [App acceptance #4](https://github.com/hughzadora/Rill/issues/4).

The `just gate` result means _this local command chain returned 0 for the current project state_. It is not a guarantee of no vulnerabilities or correct future user-visible behavior. See the authoritative [build plan](../rill-rebuild-plan.md) for the remaining delivery and acceptance phases.
