This is the product dependency map, **not** a second task database.
Current implementation authority is native parent Issue #22.

1. **Recover durable engineering controls.** Restore the product contract,
   current architecture, design, issue management, handoff and roles.
   A fresh agent can discover them without old private chat.
2. **Industrial delivery console.** React/Tailwind, not an Issue-title
   display: portfolio, actual task workstreams, blockers, acceptance,
   live PR/quality evidence, owner action and user click paths.
3. **Complete per-stack quality standard.** Real React/Node/Python/Shell
   project source, unit/component/API/CLI/integration, axe/Chrome,
   security/coverage/build and artifact evidence.
4. **New- and existing-project pilot.** Non-destructive audit, stack
   choice, native tool preservation, standard application, real checks
   and rollback.
5. **Prove genuine multiagent and handoff.** Fresh native Codex
   session, actual delegated roles and independent review; task handoff
   from GitHub/PR and docs without transcript state copies.
6. **Verify owner and release.** Real prototype, consequential design
   via harness, final click acceptance, hosted CI and focused PR.
   No automatic merge/release without protected authorization.
