# Rill Glossary

**Standard:** Versioned reusable development and quality process for
multiple new/existing project repositories.

**Project:** An actual product/repository adopting Rill; separate from
the Rill factory repository.

**Profile:** Applicable language/framework tooling, test inventory,
version locks and reviewed exceptions for a specific project.

**Candidate:** Exact commit and worktree environment under verification.

**Quality gate:** Deterministic check that really executed; a policy
declaration is not enforcement.

**Evidence:** Candidate-bound logs, test results, screenshots, review,
PR and actual user behavior that can be independently inspected.

**Native selection:** Actual harness option/approval that authorizes
a consequential owner decision; HTML click alone is not approval.

**Handoff:** Fresh agent recovery from current Issues, Git, PR and
version-controlled docs; not copied chat transcript storage.

**Parent/sub-issue:** GitHub's native task decomposition and links.
**Bug ledger:** Permanent parent for reproducible defect children.
