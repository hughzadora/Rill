CLI/MCP 契约与 quality-ready 转换

同一接口计划由 just quality profile|audit|conflicts|debt|plan|setup|run|status|reconcile|readiness --root … 和同名结构化 MCP tools 调用。profile/audit/status/conflicts/debt 查询/plan/reconcile 默认只读；setup 只在 host native approval 后写入。每个结果含 profile/release digest、revision、coverage、gate states、conflicts、debt、命令/退出/时长、外部依赖和下一步。

转换顺序：unprofiled → profiled → audited → design-approved → planned → configured → local-verified → hosted-verified → quality-ready。冲突、旧计划、失败门禁或未验证外部条件都阻止就绪；源码、锁、配置、例外或 merge-base 变化使相关证据失效。
