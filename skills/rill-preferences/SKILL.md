# Rill personal preferences

Read [personal policy](references/personal-policy.md) and the enrolled project's current approved scope. Apply those preferences while using the installed Matt Pocock method appropriate to the task.

For a raw idea, follow the project's feasibility route: Superpowers brainstorming, Matt grill-with-docs methods, and writing-for-agents when distilling the resulting agent-facing specification. Load the actual installed skills, respecting their invocation rules.

Inspect native hook execution and MCP tool results when checking enforcement, recovery, or recorded evidence. A preference being loaded is separate from a control being executed. The current task records which controls have actually passed acceptance.
