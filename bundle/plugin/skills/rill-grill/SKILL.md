# Rill Grill

Use the installed `rill-discovery` Skill as the single design-intake gate when this grill might alter product scope. Do not separately run brainstorming: the discovery gate owns that phase once.

1. Locate the exact current FR/NFR slice, original primary sources and relevant GitHub decision Issue.
2. Challenge unsupported claims, unnecessary customization, security assumptions, conflicting constraints, omitted failure paths and counterexamples. Separate factual validation from judgment.
3. Request a consequential owner choice only when no earlier approval covers it. For already-approved architecture, audit it without re-asking.
4. Record an accepted change in place in the single living PRD and its GitHub Issue/PR; never append a parallel design document or pretend that critique is independent execution review.
5. Return actionable outcomes and blockers, not fictional votes or a second project-management database.
