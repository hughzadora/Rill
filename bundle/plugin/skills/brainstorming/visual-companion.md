# Visual Companion — Rill Distribution

The optional Superpowers visual companion **server is not available in this Rill distribution**. The supplied Brainstorming Skill's original server scripts, browser event store and callback infrastructure are not packaged. Do **not** run missing `scripts/start-server.sh`, invent a web server, or claim that a visual session or selection was recorded.

For an actual design question requiring a visual comparison, use a supported **native browser/design presentation** only if available within the user's approved harness and permissions. Otherwise present a compact textual sketch, identify the visual acceptance that remains unverified, and continue without fabricating user clicks or approvals.

This file is an explicit disabled-capability notice, not an implementation of Superpowers' optional local browser tool. See the upstream [Superpowers brainstorming directory](https://github.com/obra/superpowers/tree/main/skills/brainstorming) for the original component.
